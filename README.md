# Cohort 9 - Java Fullstack Contact Management System

A full-stack Contact Management System developed as part of the Cohort 9 Java Fullstack assignment.

The project consists of a Spring Boot backend and a React.js frontend. It provides REST APIs and a user interface for managing contacts, along with validation, pagination, filtering, authentication, testing, logging, and code-quality analysis.

## Features

- Create new contacts
- View contacts
- View individual contact details
- Contact data validation
- Pagination
- Contact search and filtering
- User authentication using JWT
- RESTful APIs
- Exception handling
- Unit testing
- Application logging
- SonarQube code-quality analysis
- React.js frontend
- Responsive interface using Bootstrap
